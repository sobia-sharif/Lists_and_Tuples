# Python Data Structures: Lists & Dictionaries

This repository contains a Python notebook executed in Google Colab that covers core operations on lists and dictionaries, including dynamic input handling, sequence copying, palindrome checking, and nested data manipulation.

---

## 🚀 Key Topics & Concepts Covered

* **List Operations**:
  * Capturing dynamic input via `input()` and adding elements using `.append()`.
  * Shallow copying lists with `.copy()` and reversing elements using `.reverse()`.
  * Implementing palindrome detection algorithms by comparing lists with their reversed copies.
* **Dictionary Manipulation**:
  * Defining key-value pairs and directly modifying existing values.
  * Accessing nested structures (e.g., retrieving specific subject scores from nested grade dictionaries).
  * Extracting dictionary properties using `.keys()` and `.values()`, along with converting and counting them using `list()` and `len()`.
  * Merging and extending existing dictionaries using `.update()`.
